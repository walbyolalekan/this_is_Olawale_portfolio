# thisisOlawale portfolio

A static site: one `index.html` plus `img/` and `audio/` folders. No build step.

## Deploy on Vercel
- GitHub: upload this folder's contents to a new GitHub repo, then in Vercel choose Add New → Project, import the repo, set Framework preset to Other, leave the build command empty, and deploy.
- CLI: run `npx vercel` inside this folder and follow the prompts.

Case study pages live at `/#paidlife`, `/#vuzo`, `/#canto` and `/#bettersound`.
